# Ubuntu Mono Nerd Font (updated)

An **updated** build of [Ubuntu Mono](https://fonts.google.com/specimen/Ubuntu+Mono)
with the [Nerd Fonts](https://www.nerdfonts.com/) icon glyphs patched in.

The official [UbuntuMono Nerd Font](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/UbuntuMono)
release patches an **older upstream release** of Ubuntu Mono, so its normal
characters (x-height, cap height, letter widths) render visibly different from
the current Google Fonts version. This repository starts from the **current**
Ubuntu Mono variable font and merges the Nerd Font icon glyphs into it, so you
get:

- the **modern Ubuntu Mono look** (matching the current Google Fonts build)
- the **full Nerd Font icon set** (3,631 PUA codepoints: powerline, devicons,
  font-awesome, codicons, etc.)
- real **Bold** weight (the variable font instanced at 700, not synthesized)
- identical letterforms to the plain Ubuntu Mono — verified with 0 outline
  differences on the ASCII range

## Files

| File | Family | Weight |
|---|---|---|
| `UbuntuMonoNF-Regular.ttf` | Ubuntu Mono NF | 400 |
| `UbuntuMonoNF-Bold.ttf` | Ubuntu Mono NF | 700 |

Set `font-family: "Ubuntu Mono NF"` in your editor/terminal to use it.

## Why not the official Nerd Font build?

The official patched Ubuntu Mono is based on an older release with different
metrics (x-height 475 vs 530, cap height 619 vs 693, ascent 830 vs 932, letter
widths 500 vs 560). If that look is fine for you, use the official
[Nerd Fonts release](https://github.com/ryanoasis/nerd-fonts/releases). This
build is for people who want the current Ubuntu Mono look **plus** the icons.

## Building

This font was generated by merging the icon glyphs from the official Nerd
Fonts build into the current Ubuntu Mono variable font:

```bash
# 1. Instance the variable font at the weights you want
#    (fontTools varLib.instancer)
# 2. Merge the PUA icon glyphs from the Nerd Fonts build
#    (see merge_nerd_icons.py in this repo)
```

`merge_nerd_icons.py` copies only the PUA icon glyphs (plus cmap entries) from
a Nerd Font build into a plain font, preserving the plain font's outlines,
metrics, and family name. It strips `gvar`/`fvar`/`STAT`/`avar` on output
(adding glyphs to a variable font breaks gvar's glyph-count invariant), so the
result is a static font at the instanced weight.
